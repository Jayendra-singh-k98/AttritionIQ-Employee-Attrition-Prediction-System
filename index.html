ID3 Algorithm

Entropy · Information Gain · Recursive Splitting
01
Shannon Entropy
Measures the impurity of a node. H(S) = 0 means perfectly pure (all one class). H(S) = 1 means perfectly mixed. ID3 seeks to minimise entropy after each split.
02
Information Gain
IG(S,A) = H(S) − weighted entropy of child nodes. ID3 always selects the feature with the highest information gain as the next split — unlike CART which uses Gini impurity.
03
Recursive Partitioning
The algorithm recursively splits until nodes are pure, max depth is reached, or minimum samples are not met. Each path from root to leaf is a decision rule.
Mathematical Foundation
H(S) = −Σ p_i · log₂(p_i) // Shannon entropy of set S
IG(S,A) = H(S) − Σ (|Sv|/|S|) · H(Sv) // Information Gain for feature A
A* = argmax_A [ IG(S,A) ] // Select the best split feature

Unlike scikit-learn's DecisionTreeClassifier which defaults to Gini Impurity (CART algorithm), this project implements ID3 from scratch using pure Python. Every split is chosen by computing information gain across all features and all numeric threshold candidates (midpoints between consecutive unique values).
